# Contributing and development

This route is for workspace contributors. Application developers should begin
with the [SQLite GraphQL quickstart](../learn/sqlite-quickstart.md) and follow
the [how-to guides](../how-to/README.md).

- [Set up the workspace](setup.md)
- [Run tests and verification](testing.md)
- [Work on GraphQL changes](graphql-workflow.md)
- [Follow the release process](../operations/release/process.md)

Package-local documentation and `AGENTS.md` files add invariants and commands
for changes below that package. The [documentation index](../README.md) is the
canonical route to architecture, operations, decisions, and reference material.
